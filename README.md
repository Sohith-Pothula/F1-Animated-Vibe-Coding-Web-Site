# F1 Animated Vibe Coding Website

A futuristic Formula 1-inspired animated web experience built using Next.js, TypeScript, and modern frontend technologies.

## Features

- High-performance F1 animation sequence
- Scroll-based cinematic transitions
- Responsive modern UI
- Interactive components and sections
- Smooth animations and immersive effects
- Optimized image sequence rendering
- Vercel deployment support

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React
- Vercel

## Installation

```bash
npm install
npm run dev
